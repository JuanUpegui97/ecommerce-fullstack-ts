# E-commerce Full Stack

Aplicación e-commerce full stack desarrollada como proyecto de portafolio.

## Tecnologías

### Backend
- Node.js
- TypeScript
- Express
- PostgreSQL

### Frontend
- React
- TypeScript
- Vite

## Arquitectura

El proyecto está dividido en frontend y backend, ejecutados de forma independiente.

El frontend consume las APIs del backend mediante HTTP.

### Backend

Organizado en:

- Controllers
- Services
- Repositories
- Routes
- Middlewares
- DTOs
- Schemas
- Types
- Database migrations

### Frontend

Organizado en:

- Components
- Pages
- Context
- Services
- Types
- Assets

## Funcionalidades

- Autenticación de usuarios
- Autorización basada en roles
- Rutas protegidas
- API REST
- Gestión de usuarios
- Gestión de productos
- Subida de imágenes
- Conexión con PostgreSQL
